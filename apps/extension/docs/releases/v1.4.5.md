## 中文

### ✨ 新功能
- 批量 AI 整理支持仅重新分类、仅重新打标和完整整理。
- 新增小模型模式，分步生成摘要、分类和标签，并保存各 AI Provider 的连接配置。
- WebDAV 支持独立配置实时、启动和定时同步策略。

### 🐛 问题修复
- 修复多页面并发写入书签时的数据覆盖，以及 JSON 导入导出丢失 Markdown 正文的问题。
- 修复 WebDAV 正文解码、分类图标和删除记录同步问题，保护同步期间发生的本地编辑。
- WebDAV 使用服务端独占锁；不支持锁的服务会停止同步并提示，避免不安全地覆盖数据。
- 修复部分浏览器书签栏节点 ID 不兼容的问题，并优化分类树间距与文字剪藏卡片展开体验。

### ⚡ 性能优化
- 按正文指纹传输变化内容，并分批修复旧版本遗留的缺失正文。

## English

### ✨ Features
- Batch AI organization supports recategorization, retagging, and full organization.
- Add small-model mode for step-by-step summaries, categories, and tags, with saved connection settings for each AI provider.
- Configure real-time, startup, and periodic WebDAV sync independently.

### 🐛 Bug Fixes
- Prevent concurrent bookmark writes from overwriting data and preserve Markdown content in JSON imports and exports.
- Fix WebDAV content decoding, category icons, and deletion synchronization while protecting local edits made during sync.
- Use server-side exclusive WebDAV locks; stop with an error when locking is unsupported to prevent unsafe overwrites.
- Support varying browser bookmark-bar IDs and improve category-tree spacing and expandable text-clip cards.

### ⚡ Performance
- Transfer changed content using fingerprints and repair missing content from older versions in batches.
