# HamHome v1.4.4 Release Notes

> Maintainer note: v1.4.3 was tagged and submitted from `feat/agent-runtime-upgrade` (ba32f55) and never reached `main`. v1.4.4 merges it back, so this release keeps every 1.4.3 feature (Read later, tab center, archive, budgets) and adds the changes below on top of it. Submit with Node 22 from a clean checkout (see `docs/build-and-release.md`).

The section below is the GitHub Release body.

---

## 中文

### ✨ 新功能
- 收藏页新增分类树：左侧显示可展开的多级分类及书签数量，选中父分类时一并列出子分类下的书签；列表上方的面包屑和子分类按钮可以逐层跳转。
- 侧边栏收起后保留图标列，悬停显示名称；底部的存储和同步摘要收起后变为图标按钮。
- 存储管理的数据概览卡片按宽度自动排列，按钮文案不再溢出。
- 扩展名称和中英文简介更新为"AI 书签管理与网页收藏"定位。

### 🐛 问题修复
- Agent 不再能修改 WebDAV 同步开关和地址，只能读取同步是否开启、地址和凭据是否已填写，避免网页中的诱导文字把书签和同步凭据转发到其他服务器。
- 编辑书签：修复弹窗打开期间反复读取存储的问题；只修改标签等信息时不再清空已保存的正文；保存时不再对插件页面自动快照，原有快照不会被覆盖。
- 批量操作只作用于当前可见的条目：书签库、回收站、体检中心以及标签页中心的打开中和归档列表，切换分类、搜索或筛选后，看不到的条目会移出选择；"全选"按是否全部选中判断。
- 定期书签体检不再因为后台唤醒或修改设置而重新开始倒计时。
- 书签页的批量操作栏在窗口较窄或分类树展开时自动换行，"批量删除"等按钮不再被遮挡；子分类很多时，子分类按钮区限制高度并可滚动。

## English

### ✨ Features
- Add a category tree to the library: nested categories with bookmark counts on the left, and selecting a parent category also lists bookmarks in its sub-categories. A breadcrumb and sub-category chips above the list let you move through the levels.
- Keep an icon column when the sidebar is collapsed, with names on hover. The storage and sync summary at the bottom becomes icon buttons.
- The storage overview cards now adapt their columns to the available width, so button labels no longer overflow.
- Update the extension name and bilingual summaries around AI bookmark management and web clipping.

### 🐛 Bug Fixes
- The Agent can no longer change the WebDAV sync switch or address. It only reads whether sync is on and whether the address and credentials are filled in, so text on a web page cannot redirect your bookmarks and sync credentials to another server.
- Editing a bookmark no longer re-reads storage in a loop while the dialog is open, no longer erases the stored page text when you only change tags or other details, and no longer snapshots the extension page over the bookmark's existing snapshot.
- Bulk actions only apply to visible items in the library, trash, health center, and the tab center's open-tabs and archive lists. Items hidden by a category, search or filter change leave the selection, and "select all" checks whether every visible item is selected.
- The scheduled bookmark health scan no longer restarts its countdown whenever the background service wakes up or settings change.
- On the bookmarks page, the batch-action bar wraps when the window is narrow or the category tree is open, so buttons such as batch delete stay visible. Many sub-categories now scroll inside a height-limited area.
